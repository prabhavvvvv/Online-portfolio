▶️ Watch Demo

In a group, I helped develop Speech-to-Sign Aid, an interactive accessibility tool that converts live speech into real-time visual sign-based representations for Deaf and hard-of-hearing users. The application processes spoken language or captions from live input, identifies key words and phrases, and maps them to a structured vocabulary of visual signs and symbols. By transforming spoken content into synchronized visual cues, the project aims to improve comprehension speed and reduce cognitive load in fast-paced environments such as classrooms and meetings.

My Responsibilities
I contributed to building the real-time processing pipeline that ingests speech or caption data, normalizes the text, and maps it to a predefined library of sign and symbol animations. I helped design the rule-based translation system used to detect keywords and phrase structures and connect them to corresponding visual outputs. Additionally, I worked on integrating the backend logic with the frontend rendering system to ensure low-latency, synchronized display of visual signs, and implemented fallback handling for unsupported or out-of-vocabulary words.
What I Learned
Through developing Speech-to-Sign Aid, I gained hands-on experience working with real-time data processing, speech-to-text systems, and rule-based NLP mapping approaches. I also learned how to design for accessibility constraints, balance speed with accuracy in real-time systems, and build fallback mechanisms for incomplete language coverage while maintaining usability in live environments.

Basketball Trade Simulator

▶️ Watch Demo

I developed an interactive Basketball Trade Simulator in Java that allows users to act as a general manager making roster decisions for a fictional NBA team. The objective was to create a decision-based simulation game that demonstrates conditional logic, user input handling, and branching outcomes. The project addresses the challenge of building engaging, interactive applications using core programming concepts. The final product is a fully functional console-based game where user choices directly influence different career and team outcomes.

My Responsibilities
I independently designed and developed the entire application from start to finish. I implemented all core functionality, including user input handling using the Scanner class, decision-based branching using nested if-else statements, and game logic that determines different outcomes based on player choices. I also structured the flow of the simulation, tested different decision paths, and debugged logical errors to ensure smooth and consistent gameplay.
What I Learned
Through this project, I strengthened my understanding of Java fundamentals, especially control flow, conditional logic, and user input handling. I gained experience designing interactive programs that respond dynamically to user decisions and improved my ability to structure and debug multi-branch logic. This project also reinforced my problem-solving skills and helped me become more confident in independently building complete programs from scratch.
